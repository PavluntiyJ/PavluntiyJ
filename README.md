I build small, tested tools in Python and TypeScript.

### Projects

**[EestiHub](https://github.com/PavluntiyJ/eestihub)** · [live](https://eestihub.vercel.app)
Compares Estonia's four tax regimes side by side, in English, Estonian or
Russian. The same gross income can differ by hundreds of euros a month
depending on which one you pick.
*FastAPI · Next.js · PostgreSQL*

**[The Feed](https://github.com/PavluntiyJ/NewsAggregator)** · [live](https://news-aggregator-one-phi.vercel.app)
Offline-capable news reader with instant search and a command palette. Runs
against local fixtures with no API key, so every feature works on a fresh clone.
*Next.js 16 · React 19 · TypeScript · Playwright*

**[Trace](https://github.com/PavluntiyJ/IP-Address-Tracker)** · [live](https://ip-address-application.netlify.app/)
Resolves an IP or domain to its location, timezone and network provider on an
interactive map. The API credential never reaches the browser bundle.
*React 19 · TypeScript · Cloudflare Workers*
